Entrar no painel

O painel publica no site usando uma chave de acesso do GitHub que só você tem. Ela fica guardada apenas neste navegador.

Sem marcar, a chave fica só nesta aba e some quando você fechar o navegador. Marque só num aparelho que é seu.

Como criar a chave (uma vez só, leva 2 minutos)
  1. Entre no GitHub com a sua conta e abra Settings → Developer settings → Personal access tokens → Fine-grained tokens. Clique em Generate new token.
  2. Em Token name, escreva algo como “Painel do portfólio”. Em Expiration, escolha 90 days (evite “No expiration”: uma chave com prazo para de valer sozinha se um dia vazar; quando vencer, é só criar outra).
  3. Em Repository access, marque Only select repositories e escolha .
  4. Em Permissions → Repository permissions, ache Contents e troque para Read and write. Não precisa de mais nenhuma.
  5. Clique em Generate token, copie a chave (começa com github_pat_) e cole no campo acima.

A chave só dá acesso aos arquivos deste site. Se um dia você perder o aparelho, apague a chave no mesmo lugar do GitHub e ela para de valer na hora.

Portfólio

Envie imagens (ou cole com Ctrl+V), cole links de vídeos do YouTube e dê um título, uma categoria e uma descrição a cada trabalho. Cada trabalho pode ter até 4 imagens. Trabalho novo entra no topo (no site, os mais recentes aparecem primeiro, com a data do envio); para mudar a ordem, arraste pelo ⠿ ou use as setas. Nada vai para o site até você clicar em Publicar.

Categorias

No site, as categorias aparecem em cima da grade, nesta ordem, e só as que têm algum trabalho. Um toque nelas filtra os trabalhos. Escreva o nome em português e em inglês; as setas mudam a ordem.
